# Bitcoin Fear & Greed Sentiment vs Hyperliquid Trader Performance

## Objective
Analyze how market sentiment impacts trading performance and discover patterns that enable smart strategy decisions.

## Features
- Sentiment Distribution Analysis
- Hyperliquid Trader PnL Analysis
- Combined Insight: PnL vs Sentiment Regime
- Long vs Short Optimization Behavior

## Tech
- Python, Pandas, NumPy, Matplotlib, Colab

## Results Summary
Fear sentiment historically corresponds to higher PnL and short bias performance dominance.
